An entry for [make.fun's pump.fun paper sprint](https://make.fun/bounty/u-boothlord-pump-fun-paper-sprint-any-bot-can-f83c389b).

`main.ts` is a pump.fun paper-trading bot for the replay harness: it buys
only coins that show early reserve growth and net-buying flow, and sells
with discipline (take-profit, stop-loss, and a dead-money exit) instead of
holding everything to the end.
